A small collection of diagram and typesetting tools — built because writing the markup by hand was slower than drawing the thing.

Tools

  • Graphviz Generator Live →

    Sketch nodes and edges on a canvas, auto-layout with six engines (dot, neato, fdp, sfdp, circo, twopi), and export clean DOT. Sixteen node shapes, full edge styling, clusters, undo/redo, autosave. graphviz.busypizza.bond
  • TikZ Generator Live →

    Thirty-plus drawing tools — shapes, circuit symbols, logic gates — with pressure-sensitive Apple Pencil input. The LaTeX comes from where things sit on the canvas, so it is instant and matches exactly what you drew. Previews compile in the browser. tikz.busypizza.bond
  • Text to Speech Soon

    Paste text, pick a voice, download the audio. No account, no upload limits worth mentioning. speech.busypizza.bond
